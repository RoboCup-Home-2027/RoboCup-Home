## 为什么不直接上传原文件

目标 GitHub 仓库为公开仓库。WHEELTEC资料中的《版权声明》明确说明，未经书面许可不得复制、传播或翻译其手册、信息和材料。因此：

- 不把厂商PDF、视频、EXE、固件ZIP、机械臂ROS源码ZIP公开提交；
- 本文件只保存事实性目录、团队使用建议和文件校验值；
- 原文件继续保存在团队本地资料盘；
- 若后续获得书面许可，或迁移到访问受控且符合许可的存储，再按许可范围处理；
- 只有完全独立编写、未复制厂商受限表达且完成许可证审查的ROS2适配器、配置和比赛代码，才可以提交到本公开仓库。

## 使用优先级

### P0：拿到实物当天

1. `R550&V550随货手册.pdf`
2. `C30D主板客户端辅助质检使用手册_2025.01.13_V2.0.pdf`
3. `1.Mini小车接线说明.pdf`
4. `2.MiniROS小车问题排查与改装介绍_2024.03.08.pdf`

用途：识别接口、检查接线、完成到手自检。没有确认实物型号前，不使用固件源码。

### P1：底盘与通信开发

1. `1.STM32运动底盘开发手册_ROS教育机器人_2025.2.19.pdf`
2. `4.单片机与APP通信协议.pdf`
3. C30D 2.0 Mini小车 GMR/霍尔两套源码归档

用途：理解底盘协议、车型参数、编码器和C30D逻辑。只有确认控制板版本、编码器和车型完全匹配后才允许打开对应固件工程；默认禁止烧写。

### P2：机械臂确认后

1. `机械臂小车使用手册.pdf`（本地4/6自由度目录中的文件内容校验值相同）
2. 4自由度/6自由度ROS通信协议补充说明
3. 对应C30D 2.0 GMR/霍尔固件源码归档
4. `melodic_wheeltec_arm_20240411.zip`

机械臂ROS归档是ROS1 Melodic参考栈，不是当前ROS2 Humble比赛主线。先决定ROS1容器、ROS1/ROS2 Bridge或原生ROS2串口节点路线，再使用。

## 明确排除

- 视频教程：体积大，Git不适合；
- EXE和烧录工具：平台相关且高风险；
- 旧版A/B/C/C30D 1.0固件：实物未核型前容易误用；
- 芯片完整数据手册：比赛联调优先级低；
- MoveIt、OpenRAVE和第三方源码压缩包：可从官方来源按需获取；
- 三维模型：当前比赛软件联调不需要；
- 重复的4/6自由度机械臂通用手册：校验值相同。

## 后续允许提交的内容

实物核型后，团队可以自行编写并在许可证审查通过后提交：

- C30D/机械臂ROS2通信适配层；
- 硬件型号与接口映射；
- 经实测的参数差异；
- 不含厂商受限原文的操作记录；
- 自动化校验脚本和真机测试结果。

提交前维护来源/许可证台账，至少记录：文件来源、许可证或书面许可、是否包含厂商手册截图/表格/长段译文/源码改写、审查人和NOTICE/SPDX要求。SHA-256只能证明本地文件一致，不能证明拥有公开传播授权。
